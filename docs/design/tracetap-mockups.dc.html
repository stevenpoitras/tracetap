Brief

TraceTap — what I'm designing for

Read from the repo at stevenpoitras/tracetap, not from screenshots. A local, open-source observatory over captured agent traffic. Cost matters less than the information.

What the code gives me
  • A normalized Trajectory — ordered steps, tool calls, observations, token rollups.
  • A derived flow graph: user / thinking / assistant / tool_call / tool_result / hook / api_call / branch.
  • Hook events with trigger, decision, outcome, stdin and stdout previews, duration, exit code.
  • Context X-Ray: nine buckets per call, with new / carried / dropped segment deltas.
  • Tool tax: per-tool schema size × request count, and the dead set.
  • Recorded compactions: trigger, pre / post / dropped tokens, duration.
